# Security Policy

Reps runs entirely in the browser: there is no server and no account, and
your data stays on your device unless you export or share a backup yourself.
Security issues are still taken seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/GianSegura/reps/security/advisories/new)
instead of opening a public issue.

You can expect a first response within a week. Only the latest version
deployed at https://giansegura.github.io/reps/ is supported.
